# Example run artifacts

These are **real** outputs from AgentGymnasium's export endpoints, generated by
running the built-in demo design and scoring it with the Bridge Builder reward.
The volatile run id has been normalized to `EXAMPLE_RUN` so the files are stable.

- [`sample_report.md`](sample_report.md) — the self-contained Markdown run report
  (`GET /api/exports/{run_id}/report`). Outcome, score, full metrics table, design
  part counts, and simulation stats.
- [`sample_scorecard.json`](sample_scorecard.json) — the scorecard
  (`GET /api/exports/{run_id}/scorecard`): `score_total`, `success`, `metrics`,
  `failure_events`, `summary`, and a deterministic `improvement_hint`.

Regenerate them from a live run via the Studio **View Full Report** / **Export
Design** buttons, or the `/api/exports/*` endpoints directly.
